# DTI-PROJECT-# 🎓 Smart Budgeting for Students

Smart Budgeting for Students is a finance management application designed to help students manage their money wisely, track expenses, save regularly, and build healthy financial habits.

## 📌 Overview

Students often face challenges in managing pocket money, scholarships, part-time income, and daily expenses. This project provides a simple and effective budgeting system to help students control spending and achieve savings goals.

## ✨ Features

- 💰 Track Income (Pocket money, stipend, part-time earnings)
- 🧾 Record Daily Expenses
- 📊 Monthly Budget Planning
- 🎯 Savings Goal Tracker
- 📈 Expense Reports & Charts
- 📂 Category-wise Spending Analysis
- 🔔 Reminder for bill payments / due fees
- 🔐 Secure Login System

## 👨‍🎓 Target Users

- College Students
- University Students
- Hostel Students
- Freshers learning money management
